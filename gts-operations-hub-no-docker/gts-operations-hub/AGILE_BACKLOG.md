# GitHub Projects Agile backlog

Create a GitHub Project board with Todo / In Progress / Review / Done. Use a one-week sprint and document acceptance criteria. GitHub Projects is configured on GitHub's website, not automatically provisioned by this repository.

| Issue | Acceptance criteria |
|---|---|
| CMDB inventory | Create, list, edit and delete configuration items |
| Dependency relationships | Record and query an asset-to-asset dependency |
| Incident lifecycle | Create an incident, resolve it, and update the dashboard |
| Dashboard | Display healthy/unhealthy asset and incident counts |
| Terraform local IaC | Run init, validate, plan, apply and destroy |
| Keycloak IAM lab | Import realm, inspect roles, configure OTP on demo user |
| Kubernetes browser lab | Demonstrate scaling and pod self-healing in hosted lab |
| CI | Tests pass on GitHub Actions Windows runner |
| Documentation | Screenshots, setup steps and known limitations |
